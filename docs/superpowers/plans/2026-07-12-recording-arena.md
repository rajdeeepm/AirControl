# AirControl Recording + Arena (Spec 4) Implementation Plan

> **For agentic workers:** Executed by **Codex** (GPT-5.6) task-by-task; Claude reviews and commits. All prior plans' Global Constraints apply verbatim (env/ venv, `-p no:cacheprovider`, all 250 tests stay green, no commits from Codex, style, privacy, nothing outside the project dir).

**Goal:** User-facing custom-gesture creation with blocking quality checks, and a practice arena that turns confirm/reject into on-device learning.

---

### Task 1: Store schema v2 + gesture stats
**Files:** Modify `src/aircontrol/store.py`; Test: extend `tests/test_store.py` (append only — never edit existing tests).
**Interfaces:** `_SCHEMA_VERSION = 2`; migration adds `CREATE TABLE gesture_stats (gesture_id INTEGER PRIMARY KEY REFERENCES gestures(id) ON DELETE CASCADE, confirms INTEGER NOT NULL DEFAULT 0, rejects INTEGER NOT NULL DEFAULT 0, threshold_offset REAL NOT NULL DEFAULT 0.0, updated_at REAL NOT NULL)`; idempotent; v1 DBs upgrade in place (test: open a v1-built DB file, reopen with new code, version==2, data intact). `GestureStatsRepo` as `store.gesture_stats`: `.get(gesture_id) -> GestureStatsRecord(gesture_id, confirms, rejects, threshold_offset, updated_at)` (zeros row auto-created on first get), `.record_confirm(gesture_id)`, `.record_reject(gesture_id, offset_bump: float = 0.02)` (increments rejects and threshold_offset), `.reset(gesture_id)`. `delete_everything()` clears it too.
**Tests:** migration fresh→v2; populated-v1→v2 keeps gestures/exemplars; stats CRUD; cascade delete; delete_everything.

### Task 2: `curation.py`
**Files:** Create `src/aircontrol/curation.py`; Test `tests/test_curation.py`.
**Interfaces:** `consistency_report(takes: Sequence[Trajectory], *, resample_length=45) -> ConsistencyReport(mean_distance: float, outlier_indices: tuple[int, ...])` — pairwise `trajectory_dtw` over normalized takes; outliers = takes whose mean distance to the others exceeds 1.5× the overall mean. `prune_exemplars(trajs: Sequence[Trajectory], max_n: int) -> tuple[int, ...]` — indices to KEEP: greedy farthest-point selection on the DTW matrix seeded with the most recent take; always includes the newest; len == min(max_n, len).
**Tests:** planted outlier detected; tight cluster → no outliers; pruning a cluster+distant set keeps the distant ones and the newest; keep-count correct; deterministic.

### Task 3: `recording.py`
**Files:** Create `src/aircontrol/recording.py`; Test `tests/test_recording.py`.
**Interfaces:** `RecordingConfig(min_takes=8, max_takes=12, consistency_max_mean=0.35, confusability_min_margin=0.15, incidental_min_distance=1.0)` (module-level dataclass, values tunable); `RecordingSession(name: str, store: Store, profile: CalibrationProfile, config: AppConfig, rec_config: RecordingConfig = ...)`: internally builds `SegmentationMachine(profile.motion)` + `DtwMatcher(store)` (refreshed) + `IncidentalDensity.from_rows(profile.incidental_features)` when rows>=2; surface: `feed(frame: LandmarkFrame | None, now: float) -> TakeEvent | None` (segmentation-driven; a CandidateSegment becomes a PENDING take), `confirm_take()`, `discard_take()`, `takes_confirmed: int`, `phase` (`"capture"|"review"|"saved"|"refused"`), `finish() -> RecordingOutcome(saved: bool, reason: str, gesture_id: int | None, consistency: ConsistencyReport | None, conflict_gesture_id: int | None)`; finish() runs: consistency (mean > max ⇒ refused "inconsistent", reports outliers) → confusability: (a) for each confirmed take, matcher.match; if any existing gesture's score margin over... rule: max over takes of (top1 when matched to an EXISTING gesture) >= (1 - confusability_min_margin) ⇒ refused "too similar", conflict id reported; (b) density.distance(take) < incidental_min_distance for a majority of takes ⇒ refused "resembles desk motion"; on pass: store.gestures.add(name) + exemplars for all confirmed takes + stats row; never-skippable (no bypass parameter).
**Tests:** scripted takes via synthetic trajectory generators (reuse test_matcher.py class-generator style): happy path saves gesture with N exemplars; inconsistent takes refused with outliers; take too similar to a pre-seeded library gesture refused with that gesture id; takes resembling seeded incidental rows refused; min_takes enforced (finish before min ⇒ refused "need more takes").

### Task 4: `arena.py`
**Files:** Create `src/aircontrol/arena.py`; Test `tests/test_arena.py`.
**Interfaces:** `ArenaSession(store: Store, *, max_exemplars=15, clock=time.monotonic)`: `observe(segment: CandidateSegment, result: MatchResult, fired: bool) -> ArenaPrompt(gesture_id, top1, runner_up_id, top2)` (stored as pending); `confirm()` → adds pending segment trajectory as exemplar for the matched gesture, applies `prune_exemplars` to that gesture's exemplars when over cap (delete pruned rows via `store.exemplars.delete`), `store.gesture_stats.record_confirm`; `reject()` → `record_reject` (threshold_offset grows); `start_stress(duration_seconds=60.0)` / `stress_active` / stress bookkeeping: every `observe(..., fired=True)` during stress increments `stress_fires`; `summary() -> dict` (per-gesture confirms/rejects/threshold_offset + stress_fires). Effective-threshold hook: add `effective_t1(base: GateThresholds, offset: float) -> float = base.t1_top1 + offset` helper consumed later by pipeline (Task 5).
**Tests:** confirm adds exemplar + prunes at cap (seed 15, confirm 16th, count stays 15 and includes newest); reject bumps offset; stress counts only fired observations within duration; summary shape.

### Task 5: Wiring — CLI flows + per-gesture threshold in pipeline
**Files:** Modify `src/aircontrol/pipeline.py`, `src/aircontrol/app.py`, `src/aircontrol/cli.py`; Test `tests/test_arena_integration.py`.
**Interfaces:** pipeline: when dispatching a matched gesture, effective T1 = `gate.thresholds.t1_top1 + store.gesture_stats.get(gesture_id).threshold_offset` — implement by evaluating the gate as today, then AFTER a fire decision, additionally require `result.top1 >= t1 + offset` else convert to abstain (`reason="t1_offset"`, no dispatch, still a candidate event). app.py: `record_gesture(config, config_directory, name, model_override=None) -> int` and `arena(config, config_directory, stress: bool, model_override=None) -> int` HUD loops in the calibrate() pattern (cv2 putText instructions; keys: Space confirm-take/confirm-match, X discard/reject, Q quit; arena shows "0.91 <name> | runner-up 0.62 <name>"); both require an active profile (print a clear message and exit 2 if none) and refresh the daemon-less local matcher after saves. cli.py: `--record-gesture NAME` and `--arena` (+`--stress`) flags routed accordingly; mutually exclusive with --calibrate/--practice.
**Tests (integration, no camera):** seeded store + profile: rejected gesture's threshold_offset makes a previously-firing segment abstain with reason "t1_offset" (drive pipeline.process end to end); recording→arena round trip: RecordingSession saves a gesture, ArenaSession confirm grows its exemplars, matcher.refresh picks it up and a scripted segment dispatches its mapped action. CLI: `--help` lists the new flags; `--record-gesture` without profile exits 2 (invoke cli.main with a temp config dir and empty store path monkeypatched — no camera should be opened before the profile check; assert via a stub).
